# Droplet Map 사용법 (0.5.1)

0.5부터 **데이터 입력과 분석이 나뉩니다.** 배치 정보와 실험 데이터는 **배치 하나당 엑셀 파일 하나**(배치 파일)에 적고, Droplet Map은 그 파일들이 있는 **배치 폴더**를 읽어서 분석만 합니다. 배치 파일은 **엑셀에서** 고치고, 저장하면 Droplet Map이 바로 다시 읽습니다. 앱은 새 배치 파일을 기본 틀로 만들어 엑셀로 열어 주고, 그 뒤로는 열람과 분석만 합니다.

## 배치 파일 (배치 하나 = .xlsx 하나)
기본 시트 다섯 개로 시작하며, 시트 · 열 · 항목은 모두 추가 · 수정 · 삭제할 수 있습니다. '조건'은 입자 형성 조건을 뜻하고, 모든 시트는 **조건 ID**로 형성 조건표와 이어집니다.

| 시트 | 모양 | 내용 |
|---|---|---|
| 배치 정보 | 배치 값 | 항목 · 값 · 단위 · 구분 · 메모. 배치마다 값이 하나인 것 (배치 이름, 정제일, 컬럼, 단백질 농도, 제타 포텐셜 …). '구분'(정제 조건 / 배치 성질 / 직접 만든 범주)이 배치 지도의 범주입니다. |
| 형성 조건 | 조건표 | 조건 ID(C01 …)마다 한 행: pH, NaCl (mM), PEG (%), 단백질 (µM) … |
| 입자 형태 | 입자별 측정 | 이미지 분석의 입자 하나에 한 행 (조건 ID, 이미지, 측정값 …) |
| in vitro 실험 | 조건별 측정 | 조건 ID마다 반복 측정 (FRAP 회복률, FRAP t½, 탁도 …) |
| 세포 전달 | 조건별 측정 | 전달 실험 한 번에 한 행: 시간 · 항체 양(하위 조건), 세포질 / 입자 안 신호, 세포질/입자 비율(비어 있으면 자동 계산) |

- 열 머리는 `이름 (단위)`입니다. 열마다 **역할**이 있습니다: 조건(형성 조건) · 측정값 · 하위 조건(측정 자체의 조건: 시간, 처리 양) · 반복(이미지 · 반복 번호) · 메모(분석에 안 씀).
- 시트 모양 · 범주 · 열 역할은 숨은 시트 `_droplet`에 적힙니다. 엑셀에서 더한 열은 이름과 값으로 역할을 짐작합니다(숫자 = 측정값, 시간 · 항체 · 농도 = 하위 조건, 반복 · 이미지 = 반복, 메모 · 비고 = 메모). 직접 정하려면 열 머리 끝에 `[하위 조건]`처럼 적습니다.
- 엑셀에서 새 시트를 만들어도 됩니다. 첫 행에 '조건 ID' 열이 있으면 조건별 측정 시트로 읽고, 시트 이름이 배치 지도의 범주가 됩니다.
- 파일마다 `_사용법` 시트에 이 설명이 들어 있습니다.
- 빈칸은 '기록 안 함'이고 0으로 읽지 않습니다.
- 폴더의 `_템플릿.xlsx`가 새 배치의 시작 모양입니다. `_`나 `~$`로 시작하는 파일은 배치로 읽지 않습니다.

## 시작하기
- `파일 › 새 배치 폴더 만들기`(⌘N): 폴더와 기본 템플릿을 만들고 첫 배치 파일을 만들어 엑셀로 엽니다.
- `파일 › 새 배치`(⇧⌘N): 배치 이름을 넣으면 기본 시트 · 파라미터 틀이 들어간 엑셀 파일을 만들어 엽니다. 템플릿에서 시작하거나, 이전 배치를 복사(시트 · 열 · 형성 조건 · 배치 값 유지, 측정값은 비움)합니다.
- `파일 › 배치 폴더 열기`(⌘O): 배치 파일이 있는 폴더를 엽니다. 폴더, .xlsx, .dmap을 창에 끌어다 놓아도 됩니다.
- `파일 › 가상 예제 열기 (배치 5개)`: 만든 데이터로 된 배치 폴더 (실험값이 아닙니다).
- 0.4 이전 프로젝트(.dmap 안에 데이터)는 그대로 열려 분석할 수 있고, `파일 › 배치 파일로 꺼내기`로 배치 폴더를 만들면 그때부터 엑셀에서 고칩니다.

## 엑셀에서 고치기
- `파일 › 배치 파일 엑셀에서 열기`: 배치마다, 그리고 📐 템플릿(새 배치의 시작 모양). 배치 표의 '엑셀에서 열기'도 같습니다.
- 엑셀에서 저장하면 Droplet Map이 1–2초 뒤에 바뀐 파일만 다시 읽습니다 (작업 기록에 남음).
- `파일 › 배치 파일 점검`: 같은 조건 ID 두 번, 조건표에 없는 조건 ID, 측정값 칸의 숫자 아닌 값 등을 파일 · 시트 · 엑셀 행 번호로 보여 줍니다.
- **이미지 분석 CSV**: `데이터 › 입자 CSV · 세포 전달 CSV를 배치 파일에 넣기`(창에 끌어다 놓아도 됨). 배치를 고르고 CSV 그룹마다 조건 ID를 고르면 입자 CSV는 입자 형태 시트에, 세포 전달 요약은 세포 전달 시트에 들어갑니다. 그룹 이름은 버튼을 누를 때만 읽습니다('그룹 이름에서 찾기', '이름으로 새 조건 만들기'). 같은 데이터는 두 번 넣지 않습니다. 넣는 동안 그 파일을 엑셀에서 닫아 두세요.

## 화면과 흐름 (Droplet Map)
- **왼쪽 – 배치 › 형성 조건 목록**: 체크한 배치가 배치 지도에 나옵니다. 배치를 펼치면 형성 조건(C01 pH 7 · NaCl 150 mM …)이 보이고, 체크한 조건의 입자가 입자 지도에 나옵니다. 오른쪽 클릭으로 기준(★).
- **가운데 – 메인 흐름**: 배치 지도 · 배치 표 · 배치 비교 · 데이터(열 역할, QC).
- **입자 수준**(서브): 입자 지도 · 조건 비교 · 기준 score · 측정 시트. 처음에는 닫혀 있고, `입자 수준` 메뉴에서 열거나 배치 지도의 점을 두 번 누르면 그 배치의 입자 지도가 열립니다.
- **오른쪽 – 설정**: 가운데에서 고른 탭의 설정과 **측정값 가중치**(입자 수준에 적용).

## 배치를 설명하는 값 (배치 표)
배치 표는 보기 전용입니다 (고치는 곳은 엑셀).
- **배치 값**: 배치 정보 시트의 항목. 날짜(2026-03-02)는 날짜 차이로 계산합니다.
- **실험 데이터에서 계산** (입자 형태 시트, 조건별 측정 시트마다; 시트가 범주):
  - **경향**: 배치 안에서 조건 한 단위당 측정값 변화 (예: pH 1 오를 때 circularity 변화). 배치마다 실험한 조건이 달라도 비교할 수 있습니다. 여러 조건이 함께 바뀌면 함께 넣은 선형 회귀로 나눕니다. 하위 조건(시간 등)에 대한 경향도 냅니다.
  - **같은 조건**: 두 배치 이상이 같은 조건 세트로 실험했을 때 그 조건에서의 값.
  - **대표값**: 배치의 모든 조건의 중앙값. 입자 데이터는 기본으로 꺼져 있습니다.
  - 오른쪽에서 시트마다 세 가지를 켜고 끕니다.
- 입자 값은 전체 입자 기준 robust z의 조건별 중앙값(형태값은 크기 신뢰도 가중)과 이미지당 입자 수, 조건별 측정 시트 값은 반복 측정의 중앙값입니다.

## 배치 지도
- **거리**: 두 배치가 함께 가진 항목만 비교합니다. 수치 항목은 배치들 사이 범위 대비 차이, 범주 항목은 같으면 0 · 다르면 1. 묶음(배치 값, 경향, 같은 조건, 대표값)마다 평균하고 범주마다 거리를 낸 뒤 **범주 무게**로 평균합니다.
- **지도**: 거리를 PCoA로 2차원에 펼칩니다. 축마다 설명량과 그 축을 따라 변하는 항목을 적습니다. 점 색은 아무 항목으로.
- 오른쪽에서 범주 무게(0 = 빼기), 항목 묶음, 개별 항목을 끄고 켭니다. '배치 지도 다시 계산'(⌘B).
- 아래 탭: 범주별 지도, 거리 표, 배치 군집, 기준 배치 score (100 × (1 − 기준 배치와의 거리)).

## 배치 비교
- **항목 차이**: 두 배치의 모든 항목에서 B − A (배치들 사이 범위 대비).
- 입자 수준(입자 분석 후): 형성 조건이 모두 같은 조건끼리 짝지어 배치 간 거리, 측정값 차이, 같은 조건 기준 배치 score.

## 입자 수준
- **입자 지도**: 점 하나 = 입자 / 이미지 / 형성 조건 / 조건 값별 묶음. 색칠, 응집도, 계층 지도, 배치별 지도, 지도에 넣을 값 고르기. `입자 수준 › 입자 분석 실행`(⌘R). 배치 파일의 입자 데이터가 바뀌면 다시 실행합니다 (다른 시트만 바뀌면 결과는 그대로).
- **조건 비교**: 형성 조건의 효과를 배치 안에서 계산합니다.
- **기준 score**: 기준 조건(★)과 비교한 score.
- **측정 시트**: 조건별 측정 시트(in vitro 실험, 세포 전달, 직접 만든 시트)의 측정값을 형성 조건이나 하위 조건(시간 …)에 따라 배치별로, 조건별 요약 표, 그 조건의 입자 값과 나란히.

## 측정값 가중치
입자 수준에 적용됩니다. 0 = 빼기, 1 = 기본, 2 = 두 배.

## 저장
- 데이터는 배치 파일(엑셀)에 있습니다. `파일 › 프로젝트 저장`(⌘S)의 .dmap에는 **분석 쪽만** 들어갑니다: 배치 폴더 위치, 열 역할, 기준, 배치 지도 · 입자 지도 설정, 가중치, 열린 탭, 작업 기록. 폴더를 옮겼으면 열 때 폴더를 다시 고릅니다.
- 기능별 저장은 각 기능 메뉴에 있습니다 (그림 PNG/PDF/SVG/TIFF, 표 CSV).
- `파일 › 모든 결과 통합 저장`(⇧⌘E): 배치 지도 표, 입자 수준 결과, 측정 시트 요약, 그림, 프로젝트 파일을 한 폴더에.
