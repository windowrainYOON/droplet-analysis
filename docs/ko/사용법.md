# Droplet Map 사용법 (0.3)

## 화면
- **왼쪽 – 배치 › 그룹 목록**: 정제 배치 아래에 입자 형성 그룹과 세포 전달 그룹이 붙습니다. 배치를 체크하면 그 아래 그룹이 함께 바뀝니다. 체크한 입자 형성 그룹만 입자 지도에 표시합니다. 오른쪽 클릭으로 기준 그룹(★)을 지정·해제합니다. 아래 '조건으로 거르기'에서 조건과 값을 고르고 **이 값만**을 누르면 그 값의 그룹만 체크됩니다.
- **가운데 – 결과**: 데이터 · 조건 · 입자 지도 · 조건 비교 · 배치 비교 · 기준 score · 세포 전달 탭. 탭의 ×로 닫고, 메뉴의 `… 탭 열기`로 다시 엽니다.
- **오른쪽 – 설정**: 가운데에서 고른 탭의 설정과, 늘 있는 **측정값 가중치** 탭.

## 배치와 그룹
- **배치** = 단백질 정제 한 번. 배치 조건(정제일, 농도 …)은 조건 탭 위쪽 배치 표에 넣고, 그 배치의 모든 그룹이 물려받습니다 (그룹 표의 회색 [배치] 열).
- **입자 형성 그룹**: 형성 조건(pH, NaCl, PEG …) + 입자 CSV. **세포 전달 그룹**: 전달 조건(농도, 시간 …) + 강도 요약 CSV, 그리고 '사용한 입자 형성 그룹'.
- CSV를 불러올 때 어느 배치인지 묻습니다. 비워 두면 '배치 미지정'(노란 줄)으로 두고, 그룹 표의 배치 칸이나 '선택 그룹 → 배치 지정'으로 나중에 정합니다.
- 0.2 프로젝트를 열면 '정제 배치' 조건 열이 배치로 옮겨집니다.

## 불러오기
`파일 › 불러오기 (자동 인식)`(⌘O) 또는 창에 끌어다 놓기. 입자 CSV, 조건 CSV, 세포 전달 요약 CSV(group, region, parameter, mean …), 조건 템플릿(JSON), 프로젝트(.dmap)를 내용으로 구별합니다.

## 입자 지도
- **점 하나 =** 입자 / 이미지 / 그룹 / 조건 값별 묶음. 묶음 점은 그 입자들의 지도 위 중앙 위치에 놓이고, 크기는 입자 수를 나타냅니다.
- **색칠**: 그룹, 군집, 형태값 신뢰도, 각 조건, 각 측정값.
- **응집도**: 색 기준(범주)으로 지도가 얼마나 갈라지는지 0(섞임)–1(완전 분리).
- **계층 지도**: 군집을 골라 '선택 군집 → 하위 지도', 또는 '영역 선택' 후 '선택 영역 → 하위 지도'. 하위 지도에서는 그 입자들 안에서 다시 표준화해 작은 차이를 벌려 봅니다. 위쪽 경로(전체 › 군집 0 › …)를 눌러 돌아갑니다.

- **배치**: 전체 지도(모든 배치, 색칠 '조건: 배치'), **이 배치만으로 지도**(그 배치 입자만으로 다시 계산), **배치별 지도**(아래 탭: 지금 지도를 배치마다 나눠 같은 좌표로 보기, 또는 배치마다 따로 계산).

## 조건 비교와 배치 비교
- 조건 비교에서 형성 조건의 효과는 배치 안에서 계산합니다 (배치 차이가 pH 효과처럼 보이지 않게). [배치] 조건은 배치 중앙값끼리 비교하고, 배치가 3개 미만이면 숨깁니다.
- **배치 비교** 탭: 형성 조건이 모두 같은 그룹끼리 배치를 짝지어 배치 간 거리, 두 배치의 측정값 차이(B − A), **기준 배치 score**(각 그룹을 기준 배치의 같은 조건 그룹과 비교)를 봅니다.

## 세포 전달
그룹별로 입자 안 / 세포질(입자 제외) 강도를 채널마다 보여 주고, 세포질/입자 비율도 계산합니다. 조건 탭 세포 전달 표에서 '사용한 입자 형성 그룹'을 고르면 '사용한 입자와 나란히' 탭에 그 입자의 측정값과 기준 score가 함께 나옵니다.

## 지도에 넣을 값
입자 지도 설정의 '지도에 넣을 값'에서 체크를 끈 측정값은 지도 좌표와 군집 계산에서 빠집니다. 조건을 고르고 값의 체크를 끄면 그 값의 그룹이 지도 계산에서 빠집니다 (예: pH 8 빼기). '왼쪽에서 체크한 그룹만으로 지도 계산'을 켜면 왼쪽 목록의 체크가 계산 대상이 됩니다. 기준 score와 조건 비교는 계속 모든 값을 씁니다. '지도 다시 계산'을 누르면 반영되고, 설정은 프로젝트에 저장됩니다.

## 측정값 가중치
0 = 빼기, 1 = 기본, 2 = 두 배. 기준 score는 바로 다시 계산되고, 지도는 '지도 다시 계산'(또는 자동 재계산 체크)으로 반영됩니다. 특정 값의 가중치를 올리면 그 값으로 지도가 더 갈라지고 응집도가 오릅니다.

## 저장
- 기능별 저장은 각 기능 메뉴에 있습니다 (그림 PNG/PDF/SVG/TIFF, 표 CSV).
- `파일 › 모든 결과 통합 저장`(⇧⌘E): 고른 항목을 새 폴더에 CSV·PNG·설정값과 프로젝트 파일까지 함께 저장.
- `파일 › 프로젝트 저장`(⌘S): 데이터, 조건, 설정, 가중치, 열린 탭, 보던 화면, 작업 기록까지 저장.
- `파일 › 작업 기록 보기`(⇧⌘L).
